Practical scRNAseq Analysis with R

Practical scRNAseq Analysis with R

Ming Tommy Tang

2026-03-15

Prerequisites

Welcome! I’m Tommy, and I wrote this book because I wish something like it existed when I first started analyzing single-cell RNA-seq data. Back then, I spent way too much time piecing together tutorials, Stack Overflow answers, and Bioconductor vignettes just to get a basic pipeline working.

This book is what I would hand to a new student or postdoc in my group. We’ll work through a real dataset – human PBMCs from a published study – from raw sequencing data all the way to biological interpretation. Every line of code runs. Every step is explained. No hand-waving.

What You’ll Learn

By the end of this book, you will be comfortable with the full single-cell analysis workflow:

  • Getting data into R: Download public scRNAseq data and quantify it with simpleaf/alevin-fry (yes, there is life beyond Cell Ranger)
  • Quality control: Identify empty droplets, doublets, and dying cells – and understand why we remove them
  • The Seurat workflow: Normalization, PCA, integration, UMAP, clustering – each step explained so you actually know what the functions are doing under the hood
  • Cell annotation: Label your clusters using reference-based methods (SingleR, clustifyr, label transfer) and learn when to trust the results
  • Biological interpretation: Run gene set enrichment analysis with clusterProfiler to connect your clusters to biology

What You Need Before Starting

Software:

  • R version >= 4.3.0 (required for Bioconductor 3.18+)
  • RStudio (latest version recommended)
  • Git for cloning the repository

R experience: I assume you are not a complete beginner. You should be comfortable with data frames, calling functions, using the pipe operator (%>% or |>), and basic dplyr operations. If mtcars %>% filter(cyl == 6) looks foreign to you, I’d recommend working through the first few chapters of R for Data Science before diving in here.

Computing Resources

Single-cell analysis is memory-hungry. You’ll want at least 8GB of RAM (16GB+ is better), and about 10GB of free disk space for the data and results. Some steps like cell annotation and GSEA will take a few minutes to run – grab a coffee.

System Dependencies

If you’re on Unix/Linux/macOS, some R packages need system libraries to compile. If you run into cryptic installation errors, this is usually why:

macOS (using Homebrew):

brew install libxml2 openssl curl libgit2

Ubuntu/Debian:

sudo apt-get install -y \
  libxml2-dev libssl-dev libcurl4-openssl-dev \
  libfontconfig1-dev libfreetype6-dev libpng-dev \
  libtiff5-dev libjpeg-dev libharfbuzz-dev \
  libfribidi-dev libgit2-dev

How to Use This Book

The best way to learn this material is to run the code yourself as you read. Don’t just read passively – open the Rmd files in RStudio and execute the chunks one by one. Change a parameter. See what breaks. That’s how you actually learn.

The chapters are designed to be worked through in order, since each one builds on the previous. But if you already have your data quantified, you can jump to Chapter 2 (QC). If you already have a clean Seurat object, start at Chapter 3. I save intermediate objects at the end of each chapter so you can pick up wherever you need to.

For setup, follow the instructions in the README.

The Dataset

Throughout this book, we work with a real dataset: human PBMCs from Simoni et al. (2019). It’s 4 samples from 2 donors, comparing resting vs. CD3/CD28 activated T cells, sequenced with 10x Genomics 3’ v2.

I chose this dataset because PBMCs are well-characterized (you’ll have reference datasets to validate your annotations), the sample size is manageable for a course, and the resting vs. activated comparison gives you something biologically interesting to find.

GEO Accession: GSE126030

Reproducibility

One thing I care deeply about is reproducibility. Nothing is more frustrating than following a tutorial and having it break because of package version mismatches. This project uses renv to lock down every package version, so when you run renv::restore(), you get the exact same versions I used.

First-time setup (do this once):

  1. Clone the repository
  2. Install renv: install.packages("renv")
  3. Restore packages: renv::restore() – this takes 30-60 minutes, so plan ahead
  4. Download data: source("scripts/download_data.R")

See the README for the full setup walkthrough.
